# Student Management System

A Spring Boot web application for managing student records, built with Java and Maven.

## Tech Stack

- **Java 21**
- **Spring Boot**
- **Maven**

## Getting Started

### Prerequisites
- Java 21 installed
- Maven (or use the included `mvnw` wrapper)

### Run the application

```bash
# Using the Maven wrapper
./mvnw spring-boot:run

# On Windows
mvnw.cmd spring-boot:run
```

The application will start on `http://localhost:8080`.
